# 🎨 **K72 — ANIMATION REACT APP**

A **high-energy, animation-driven React application** focused on **smooth motion, scroll-based effects, and modern UI interactions**.
Built to explore **creative frontend animations** and push the boundaries of user experience 🚀

---

## ⚡ **WHAT’S INSIDE**

* 🔥 **Ultra-smooth animations using GSAP**
* 🌀 **Scroll-based interactions with ScrollTrigger**
* ⚛️ **React + Vite for lightning-fast performance**
* 📱 **Fully responsive layout across devices**
* 🎯 **Clean and scalable component-based architecture**
* 🎨 **Modern UI with engaging visual transitions**

---

## 🧠 **PROJECT PURPOSE**

This project focuses on:

* 🎬 Exploring **creative motion design in web apps**
* 🧩 Learning **GSAP integration with React**

* 📜 Experimenting with **scroll storytelling techniques**

## ⚙️ **HOW IT WORKS**

* GSAP handles **high-performance animations**
* ScrollTrigger enables **scroll-based animation control**
* React manages **component rendering and state**
* Vite ensures **fast development and optimized builds**

👉 Animations are triggered based on:

* Scroll position
* User interaction
* Component lifecycle
